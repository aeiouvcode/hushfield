# Hushfield

A small ambient place. Open `index.html` from a local HTTP server (`python3 -m http.server 8787`) or static hosting. No build, accounts, dependencies, telemetry, storage or external requests. Mobile-first canvas, three original procedural scenes: field, shore, rain. The weather, light and motion unfold without a task or reward. Sound is off until tapped. A locally synthesized, softly filtered lofi bed uses struck-key tones, a warm four-chord progression, sparse melody, slow 72 BPM pulse with gentle swing, and filtered grain. Field, shore and rain have restrained variations. Tap again to mute; hiding the tab suspends sound and requires another tap. No audio file downloads. Headless level and CPU tests pass, but human listening and physical-phone audio performance remain unverified.

The field is the lead scene: sunset, distant wheat, a seated figure held in stillness, moving heads of grain and light. Shore has a bounded, decaying touch ripple field; taps disturb the water and it settles rather than fading a painted ring. Rain has a gentle, intermittent front. A `prefers-reduced-motion` setting freezes incidental movement and disables automatic rain; direct water touches still work. A hidden `?test=1` flag exposes `window.__hushfield` for local regression tests and is not a user feature.

Security: strict local-only CSP, no dynamic HTML from input, no network, no persistence. The prototype deliberately avoids the KIN engine's high-cost caustic and fish draws: this is a distinct scene, not a copy of KIN's app. Inspired by Naksh's field-at-sunset reference and the pond's water-memory idea; no outside image, model, sound or code assets. Local-only until approval. See `PLAN.md` and `STATE.md` for measures and gaps.
